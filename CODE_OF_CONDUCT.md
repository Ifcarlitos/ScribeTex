# Código de conducta

Queremos una comunidad respetuosa para personas con distintos niveles de experiencia y procedencias.

## Comportamiento esperado

- Sé respetuoso, claro y paciente.
- Critica las ideas y el código, no a las personas.
- Acepta correcciones y explica las decisiones con contexto.
- Respeta la privacidad: no publiques información personal sin permiso.

No se permiten el acoso, las amenazas, los insultos discriminatorios, el contenido sexual no solicitado ni la publicación de información privada.

## Moderación

Este código se aplica a issues, pull requests, revisiones y demás espacios oficiales del proyecto. El mantenedor puede pedir cambios, retirar contenido o limitar la participación para proteger a la comunidad. Las decisiones deben atender al contexto y aplicarse de forma proporcional.

Usa las opciones de denuncia de GitHub para contenido abusivo. No repitas públicamente datos privados al comunicar una incidencia. Si necesitas un canal privado del proyecto y no está disponible, pide al mantenedor que lo habilite sin incluir información sensible en el mensaje público.
