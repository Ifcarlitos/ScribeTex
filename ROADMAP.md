# Hoja de ruta

Esta lista orienta el desarrollo; no supone fechas de entrega ni compromisos de disponibilidad.

## Disponible en 0.1.0 alpha

- Editor visual, cinta de herramientas, estilos y formato.
- Tablas, imágenes locales y estructuras matemáticas básicas.
- Documentos editables `.scribetex` y borrador local.
- Serializador LaTeX, motor incluido y visor PDF integrado.
- Instaladores Windows, Linux y macOS Intel/Apple Silicon.
- Pruebas del serializador y del backend PDF en las cuatro variantes.
